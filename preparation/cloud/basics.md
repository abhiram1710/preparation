# Cloud Computing Basics — Day 1

## What is Cloud Computing?

Cloud computing means using computing resources such as:

- Servers
- Storage
- Databases
- Networking
- Software

through the internet.

Instead of managing everything yourself, you use resources provided by a cloud provider.

---

# Benefits

## 1. Cost Saving

No need to buy and maintain expensive physical servers.

## 2. Scalability

Resources can be increased or decreased according to demand.

## 3. Accessibility

Services can be accessed through the internet.

## 4. Flexibility

Resources can be used when required.

## 5. Reliability

Cloud providers can provide redundancy and backup.

---

# Cloud Service Models

## IaaS

Infrastructure as a Service.

Provides:

- Virtual machines
- Storage
- Networking

Example:

AWS EC2

---

## PaaS

Platform as a Service.

Provides a platform for developing and deploying applications.

Example:

Google App Engine

---

## SaaS

Software as a Service.

Provides ready-to-use software through the internet.

Examples:

- Gmail
- Google Docs
- Microsoft 365

---

# Easy Memory Trick

IaaS → Infrastructure

PaaS → Platform

SaaS → Software
