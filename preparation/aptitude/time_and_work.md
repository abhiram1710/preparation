# Time and Work — Day 1

## Basic Concept

If A completes a work in 10 days:

A's one-day work:

1/10

If B completes it in 20 days:

B's one-day work:

1/20

Together:

1/10 + 1/20
= 2/20 + 1/20
= 3/20

Therefore:

Time = 20/3 = 6⅔ days

---

# Shortcut Formula

If:

A takes x days

B takes y days

Together:

xy / (x + y)

Example:

A = 10 days
B = 20 days

Time:

(10 × 20) / (10 + 20)

= 200 / 30

= 20/3

= 6⅔ days

---

# Important Formula

Work = Rate × Time

One-day work = 1 / Number of days

Together work = Sum of individual one-day works

---

# Placement Tip

Always convert "number of days" into "work done per day".

Example:

10 days → 1/10 work per day
20 days → 1/20 work per day
